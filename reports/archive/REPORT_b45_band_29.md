## 0. 측정 프로토콜

지표명은 5축을 전부 명시한다 — **가중치**(`.live` / EMA) × **경로**(in-loop / harness) ×
**표본**(1 / 20 samples) × **기준**(valid / strict) × **집계방식**(단일시도 / pass@k / selection / coverage).

아래 표는 전부 **harness 경로**(`experiments/sweep_harness.py`), **20 samples**, **harness seed 0/1 평균**이다.
가중치는 열로 분리했다.

| 열 이름 | 정의 | 소스 키 |
|---|---|---|
| 단일시도 valid | N×B 표본 전체의 valid 평균 ≡ pass@1 | `prior_all_samples.valid` |
| coverage@20 | 퍼즐별 (발견한 valid∧consistent 서로 다른 해 수) / (sidecar per-x 전체 해 수)의 평균 | `coverage_at_20.coverage` |
| pass@20 | 20표본 중 valid 1개 이상인 퍼즐 비율 | `pass_at["20"]` |
| majority@20 | 최빈 보드(동률은 최초 출현)의 valid | `majority_at_N_valid` |
| verifier@20 | `lrpm_head` 점수 최고 보드의 valid (라벨 미사용) | `verifier_selected_at_N_valid` |
| distinct@20 | 서로 다른 보드 개수 평균 (**다양성이지 정확도가 아니다**, 범위 1~20) | `distinct_at_N_mean` |

체크포인트: `step_N` = 편향보정 EMA 사본, `step_N.live` = raw SGD 가중치 (`pretrain.py:737,741`).

## 6. 읽히는 것

seed가 각 1개씩(4.5만 3개)이므로 순위를 단정하지 않는다. 아래는 데이터가 지지하는 범위까지만이다.

1. **4.5 재현은 실패했다.** 기존 s0 = 95.23%(harness)에 대해 s1 = 91.02%, s2 = 90.52%.
   3 seed 평균 92.26%, 폭 4.71%p. 4.5는 이 대역의 최적점이 아니다.
2. **대역 최고는 β=5.0** (98.82% | 99.37%), 다음이 5.6 (98.47% | 98.33%). 4.5보다 3.2~3.6%p 높다.
3. **β와 성능은 단조가 아니다.** 4.0(71.05) → 4.2(94.72) → 4.5(90.8) → 4.8(96.94) → 5.0(98.82)
   → 5.2(93.66) → 5.6(98.47). 5.2의 함몰은 §2의 마지막 구간 진동(38.86% → 93.91%)과 같은 현상으로 보이나,
   seed 1개라 대역 특성인지 이 run의 사고인지 구분하지 못한다.
4. **이륙 step도 β와 단조가 아니다.** 5.6이 17085로 이르고 4.5가 19363~21641로 가장 늦다.
   "큰 β일수록 늦게 이륙"이라는 사전 예상과 반대 방향이다.
5. **논문 대비**: 단일시도 valid는 98.82 vs 99.7±0.3으로 근접했다. coverage는 99.37 vs 90.3±1.9로
   우리가 9%p 높은데, 이는 §4의 해 개수 분포 차이 때문이며 우열로 읽으면 안 된다.
6. **strict-valid 괴리**: `.live` 기준 최대 3.31%p(b400: 71.05 vs 67.74), β≥4.2에서는 0.45%p 이하.
   b400의 consistent 95.08%가 대역 내 최저다.
