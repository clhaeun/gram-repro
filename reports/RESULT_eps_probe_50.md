## ② 추론 시 ACT 작동 여부 — 코드 판정

`models/recursive_reasoning/gram.py:613-633`

```python
with torch.no_grad():
    new_steps = new_steps + 1
    is_last_step = new_steps >= self.config.halt_max_steps
    halted = is_last_step
    # if training, and ACT is enabled
    if self.training and (self.config.halt_max_steps > 1):
        # NOTE: During evaluation, always use max steps, this is to guarantee
        #       the same halting steps inside a batch for batching purposes
        if self.config.no_ACT_continue:
            halted = halted | (q_halt_logits > 0)
        ...
```

- halt 분기 전체가 `if self.training` 안에 있다. `pretrain.py:686` 이 eval 전에
  `model.eval()` 을 부르므로 추론 시 `halted = is_last_step` 만 남는다.
- `no_ACT_continue: true` 의 `q_halt_logits > 0` 도 같은 블록 안이다 (gram.py:626-627).
- 따라서 추론 시 모든 샘플이 정확히 `halt_max_steps`(=16) 번 돈다.
  `models/losses.py:91` 의 `"steps": torch.where(valid_metrics, new_carry.steps, 0).sum()`
  는 이 값을 그대로 세므로 all/steps = 16.0000 고정이 된다.
- 같은 게이팅이 `trm.py:275`, `trm_singlez.py:272`, `hrm.py:276` 에도 동일하게 있다.
  주석 문구까지 같다 (TRM 상속분).

  `(q_halt_logits >= 0) == seq_is_correct` 의 비율이다. 궤적 halting 과 무관하며,
