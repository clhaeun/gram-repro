# GRAM Reproduction

Reproduction and analysis of GRAM based on [TinyRecursiveModels](https://github.com/SamsungSAILMontreal/TinyRecursiveModels).

Reproduced the model and training/evaluation pipeline for N-Queens, Graph Coloring, and Sudoku. Experiments included single-sample and multi-sample evaluation.
